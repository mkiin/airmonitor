IMPLEMENTED STATE MACHINE

SCD41 測定タスクの状態遷移

env_measure_run() の現在の実装です。矢印の時間だけ単一の esp_timer をセットし、taskmng のコールバックが測定タスクへ通知します。通知を受けると遷移先の処理を実行します。

状態遷移図

成功・通常の進行 失敗・未準備からの再試行 起動・期限通知

ハンドルの所有

taskmng が単一の esp_timer_handle_t と通知先の TaskHandle_t を保持します。測定タスクはタイマーハンドルを借りて次の期限を設定します。

通信と待機の境界

scd4x_driver は短い同期I²C通信とCRC確認だけを行います。500 ms・1 ms・5秒の期限管理は測定タスクと taskmng が担当します。
